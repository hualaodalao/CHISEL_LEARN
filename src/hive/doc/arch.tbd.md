# Hive NPU Core 架构待处理问题

本文记录[总体架构](arch.md)的审查问题、处理边界与状态。问题关闭需经过人工审查；“待人工审查”不等于已经批准。

状态定义：

- **待处理**：尚未开始分析或修改；
- **处理中**：当前轮次正在分析或修改；
- **暂缓**：保留问题与未冻结边界，当前轮次不继续处理；
- **待人工审查**：修改已完成并完成一致性检查，等待人工确认；
- **已关闭**：人工确认后关闭。

## 本轮处理边界

2026-10-27 用户确认 P0-3 审查完毕，批准配置与候选冻结阶段门已落入 `arch.md`，状态改为“已关闭”；P0-1/P0-2 保持关闭。G0 为 512 KiB/core、4 GiB LPDDR4x x32，后续 Pro 为 1 MiB/core、8 GiB x64，16 GiB 为非基线扩容。规范通过不等于物理支持或持续性能已通过：器件密度、rank、controller/PHY 和板级映射仍按阶段门验证。

P0-4其余协议按用户要求暂缓。用户本轮已明确主CPU与NPU之间采用软件Queen任务管理；local CPU/VPU均属于NPU core，仓库外仅指实现来源。主CPU不管理scheduler，local CPU通过scheduler使用GEMM/DMA并直接管理VPU；不再保留软件队列/硬件ring为并列未选方案。AXI、任务传输/通知、同步生命周期、fence/drain、可见性、原子与错误协议仍待冻结，tracing独立，不能因层次明确而关闭整个P0-4。

本轮重新评估P0-5/P0-6：语言模型signoff已批准采用官方 `Qwen/Qwen3-0.6B-FP8` 与社区 `RedHatAI/DeepSeek-R1-Distill-Qwen-1.5B-FP8-dynamic`，并批准从相同模型的原始 BF16 分别导出 MXFP8/MXFP4，先 A/B 沿 K block32、C FP32，再独立评估本地 block16 MX C 与后继算子桥接。不另换模型，也不沿用旧 Qwen2.5/INT W4A8 的默认格式与性能数值；P0-1 已关闭的 G0 模型规模/视觉范围不变，具体 FP8 身份及部署格式由本轮细化。

2026-10-27用户确认“P0-5/P0-6先闭环落入”，两个问题改为“已关闭”：关闭范围为本轮架构要求、容量/流量规划与实施验收交付清单，不是实际硬件、checkpoint部署、量化数值或持续性能通过。总体架构[第12.8节](arch.md#128-批准工作负载与持续验收门槛)记录批准服务/质量/测量规范，[第12.2节](arch.md#122-sram-容量与-tiling)与[第14.3节](arch.md#143-性能验收)记录实施交付及正式签核阶段门；条件化算例继续保留在性能分析。

批准D2048的G0/Pro平均decode为Qwen3≥6/10 token/s、DeepSeek≥2.5/4 token/s，P512 warm TTFT p95分别≤4/3 s与≤8/5 s；TPOT、Pro实测≥1.6×、驻留GEMM≥40%、质量与运行窗口同样按12.8执行。MX速度和功耗上限仍TBD，4266 MT/s、8/16 GB/s参考payload及DMA在途深度未随本轮关闭而冻结，不以目标获批宣称实测成绩。

检测基线为官方COCO预训练YOLO11n/YOLO11s，640×640、batch1，覆盖主干、attention类模块、检测头、框解码与NMS。批准G0/Pro的n≥30/48 fps、s≥10/16 fps及p95/质量门槛，见12.8；官方浮点权重仍为质量参考，FP8/MX部署artifact、导出图和量化recipe须在实施验收前冻结并验证，公开依据与算子落点见[性能分析第4章](performance_analysis.md#4-yolo-双检测模型基线与评估)。

用户澄清“不支持shared scale”专指NVFP4每16元素block scale之外的额外tensor/global scale，不撤销MX E8M0 block-scale评估路线；NVFP4两级scale不作为当前Hive能力，不能删scale或改名为MX直接使用。

P0-6的实施必须补齐逐算子精度/落点、FP8 scale与BF16层执行、MX4动态量化、FP32 C与KV流量、DMA/DRAM竞争以及全生命周期峰值证据。Qwen query宽度2048不能按hidden1024推导attention/KV；DeepSeek MX8 M32/N16完整K双B驻留579.5 KiB超过G0 512 KiB，须提交合法小M/N或经验证K流式数据计划并重新验性能。单模型条件化预算不保证多模型常驻，BF16权重量化离线完成；P1-4/P1-7/P2-1独立保留，P0-4继续暂缓。
