> 日期：2026-11-20 | 基线：`loom 1.0.0` | 目标：v1.1（async 分区 + AXI4 ID + SRAM block） | 状态：**已全部实施（2026-11-20）**

## 0. 已裁定范围

| # | 决策 | 影响 |
|---|---|---|
| 1 | **async 进 v1.1** | 分区顶层与 wrapper 支持异步边界；G9 覆盖跨边界 |
| 2 | **只做 AXI4，不做 TL-UL** | TL-UL 冻结在 v1.0 子集（单拍 Get/Put），不加多拍/poison |
| 3 | **SRAM 只生成 block，不替换宏** | 需要缓存的队列生成独立 SRAM 模块；面积评估把 SRAM 位与逻辑分开标注 |
| 4 | **不做 STA、不等时序** | 不引入 OpenSTA/OpenROAD；banked 保持 v1.0 形态，Clos 不评估 |

默认参数（可推翻，不阻塞开工）：

- AXI4 ID 宽度默认 **4 bit**（上限 8），按 master 命名空间隔离（高位置 master 序号，低位置 AXI ID）。
- AXI4 只做 **ID 透传**，不实现重排引擎：fabric 本身按 (src, class) 保序，同 ID 顺序天然保持；不同 ID 可交错但不主动乱序。
- async 边界每侧使用各自分区时钟/复位；FIFO 指针在本域复位，跨域只同步 gray 码。复位先后不做跨域握手（文档明确约束）。
- SRAM 生成的判定阈值：队列总位数 `depth × width ≥ 1024` 时生成 SRAM block，否则保持寄存器队列。

## 1. 目标与非目标

**目标**

- 同一 IR 可切出不同时钟域的分区，顶层按域接时钟/复位，跨域链路自动插入异步 FIFO/信用。
- AXI4 壳携带 ID，响应回显 ID；多 ID 并存不破坏既有同 ID 顺序。
- 大容量 VC 队列以 SRAM block 形式发射，面积代理区分"逻辑"与"SRAM 位"。
- G9 在异步边界上有界证明；回归、CG2–CG7 继续全绿。

**非目标**

- TL-UL 多拍、poison、AXI4 乱序重排引擎、QoS 与 ID 的组合策略。
- 真实 SRAM 宏替换、STA/功耗/布线、Clos banked。
- 跨域复位握手协议（只在文档中给出使用约束）。

## 3. 技术要点

### 3.1 async 分区

- IR 已有 `partitions[].clock`，S1 起允许分区内 Router/端点属于同一域，跨分区链路声明 `cdc: "async"`；S1–S3 检查改为"边界链路 async 时两端分区时钟不同"。
- `LmPartitionTop` 去掉 `require(!async)`，边界 req/rsp 走 `LmAsyncLink`（v1.0 已验证的双时钟构件），FIFO 深度取 IR 的 `asyncFifoDepth`。
- `LmWrapperTop` 的 IO 从单一隐式时钟改为 `Vec(nClock, clock)` + `Vec(nClock, reset)`；分区实例用 `withClockAndReset` 包裹。单域配置仍只生成一对端口。
- 信用：请求侧跨域必须保守计数（release 经 2FF 同步），沿用 `LmCdcCredit` 语义；响应侧独立信用。文档明确"每侧复位独立、跨域计数在复位后需等待同步稳定"。

### 3.2 G9 模型

- 单时钟 yosys-sat 无法直接建模双时钟；模型把跨域同步抽象为 **0–2 拍不确定延迟**，在单一抽象时钟下检查：信用不超发、FIFO 不丢不重、响应恰好一次。
- 证明的是"同步延迟任意时仍安全"，不证明物理 CDC 时序；后者仍由 `LmCdcSpec` 双时钟仿真覆盖。

### 3.3 AXI4 ID

- `LmReq`/`LmRsp` 增加 `id` 字段（宽度 = IR `axiIdWidth`，默认 4）；路由仍按 `src`（master 序号），ID 仅透传。
- `LmShellAxi4` 在 AW/AR 锁存 ID，B/R 回显；AxiLite/native/TL-UL 配置生成 0 宽或常量 ID，逐位与 v1.0 一致。
- 顺序契约：同一 (src, id) 到同一 slave 的请求与响应保持到达顺序；不同 ID 允许交错。由于 fabric 无重排，只需断言而非新增队列。
- 错误响应：`err` 与 ID 一起回显；未映射地址（若 SNet 译码在 v1.2 才做）仍由壳/stub 产生。

### 3.4 SRAM block

- 生成 `LmSramSp`（单口）与 `LmSramSdp`（简单双口）两个行为模块：同步写、同步/透明读可选，端口扁平，便于后端替换为真实宏。
- `emit` 在 `sram/` 下输出实例与 `sram/filelist.f`；manifest 记录；`--cache` 一并覆盖。
- 面积脚本：SRAM 位单独按"位 × 系数"列出（先给 0.6 µm²/bit 的占位系数并标注未校准），逻辑面积继续用 v1.0 拟合；`estimate.json` 增 `sramBits`、`sramAreaNote`，不把 SRAM 混进 crosspoint 项。

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 跨域复位先后导致首包丢失 | 高 | 文档约束 + 仿真覆盖"晚复位"场景；必要时增加复位同步器 |
| AXI ID 宽度增长导致端到端位宽膨胀 | 中 | 默认 4 bit；按 master 命名空间；非 AXI4 配置零开销 |
| SRAM 行为模型与后端宏不一致 | 中 | 端口契约冻结在 `LmSram*`；后端替换只改实现不改端口 |
| 形式化抽象过于宽松 | 中 | 明确"同步延迟 0–2 拍"的抽象边界，物理 CDC 由双时钟仿真兜底 |
| 调度挤压 | 低 | S3 与 S4 并行；S5 的 GUI 项可降级为文档 |

偏差与范围调整：

- **CDC 归属**：计划写"`LmPartitionTop` 边界走 `LmAsyncLink`"，实际由 wrapper 在切分边插入。分区的边界端口保持各自域内寄存的正确契约，wrapper 才知道两侧时钟，职责更清晰；效果相同。
- **多域端口**：按域的时钟用 `Vec[Bool]` 输入再 `asClock`，没有改 Chisel 的隐式 `clock`；单域配置端口与行为逐位不变。
- **SRAM 形态**：只生成单口 `LmSramSp`（本设计中推断存储器均为单口读/写队列）；未生成 `LmSramSdp`，避免无使用方的空壳。面积字段命名为 `sramAreaProxyUm2` 而非 `sramAreaNote`，并把假设写进 `assumptions`。
- **顺序检查**：同 (src,id) 保序由"无重排引擎"的结构保证；运行时只加"A/B/R 回显同一 ID"断言，未新增按 ID 的记分板。
- **未做**：TL-UL 多拍/poison、AXI4 乱序重排、跨域复位握手、真实 SRAM 宏替换、STA（均按裁定留在后续）。
